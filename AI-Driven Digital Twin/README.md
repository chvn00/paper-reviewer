# AI-Driven Digital Twin Framework for Strategic Operations Management

This project contains the initial manuscript and MATLAB simulation code for a paper intended for an MDPI journal.

## Structure

- `paper/main.tex`: Initial manuscript draft.
- `matlab/GATrESN_Digital_Twin_Framework.m`: Main reproducible Genetic Algorithm + Transformer-style attention + Echo State Network model.
- `matlab/Legacy_Baseline_Digital_Twin_Framework.m`: Earlier baseline script retained only for comparison.
- `data/`: Generated synthetic operational dataset.
- `results/`: Scenario result tables generated by MATLAB.
- `figures/`: Figures generated by MATLAB for manuscript use.
- `references/references.bib`: Initial bibliography file.

## Current Methodological Position

The study is framed as a simulation-based case study using a synthetic strategic operations dataset. This is the recommended and defensible approach when real enterprise data are not available.

## Parallel Execution

`matlab/GATrESN_Digital_Twin_Framework.m` requests a local parallel pool with up to 12 workers, matching a 12-core Mac mini M4 Pro configuration. If MATLAB has Parallel Computing Toolbox, the GA-based strategic optimization runs with `parfor`. If the toolbox is not available, the script automatically falls back to serial execution while preserving reproducibility.

Parallel reproducibility is controlled by assigning a deterministic GA seed to each optimized decision instance.

## Execution Modes

The main script includes three execution modes controlled by the `runMode` variable near the top of the file:

- `quick`: small prototype run for debugging.
- `paper`: main article-scale experiment with 18 sites, 12 product families, 520 periods, 1200 decision instances, and 25 Monte Carlo scenarios per GA candidate.
- `stress`: larger scalability run with 32 sites, 20 product families, 720 periods, 3000 decision instances, and 40 Monte Carlo scenarios per GA candidate.
